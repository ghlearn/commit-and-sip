How this was built

Commit & Sip was built with GitHub Copilot. The booth screen is a canvas: a small web app that runs inside the GitHub Copilot App as an extension. Scores come from a fixed rubric in the code, not from an AI model. This leaderboard is a small Node.js service on Azure App Service, set up with Bicep. Changes were reviewed with Copilot code review before merging, and GitHub Actions checks the repository.
